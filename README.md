# Next.js Sandbox

Next.js の学習・技術検証用リポジトリです。

Next.js や周辺技術を学習・検証し、
次のプロダクト開発へ活かすことを目的としています。

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Prisma
- Supabase
- Vercel

## Learning Topics

- App Router
- CRUD
- Authentication
- Prisma ORM
- Supabase
- Server Actions
- Route Handlers
- Vercel Deployment
